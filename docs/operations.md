# הפעלה, בדיקות ופריסה

Node.js 22; התקנה באמצעות npm ci. הבנייה היא סטטית ב־dist עם נתיבי assets יחסיים, כולל קובץ Worker וגופנים מקומיים. אפשר לאחסן בכל שרת סטטי ב־HTTPS, כולל תחת תיקיית GitHub Pages. אין משתני סביבה או סודות להרצת האפליקציה.

- `npm run check:fast`: יחידה/רכיב ו־TypeScript.
- `npm run check:full`: הבדיקות ובניית production.
- `npm run check:release`: הכל, כולל Playwright במחשב וב־Pixel 7.
- `npm run lint`: בדיקת lint לבחירה.

Workflow האיכות רץ בכל PR. הפריסה ב־main מבצעת שוב את שער השחרור, מכינה את Pages, מעלה dist ופורסת. לפני הפריסה הראשונה בעל המאגר צריך לבחור פעם אחת Settings → Pages → Build and deployment → Source: GitHub Actions. ה־GITHUB_TOKEN של Actions אינו מוסמך להפעיל Pages במאגר חדש. לא נדרש סוד נוסף אחרי הפעלה זו.

אין למזג שינוי לפני שבדיקות האיכות עברו. יש לבדוק את תוצאת workflow הפריסה ואת האתר החי לפני טענה שהפרסום הושלם. חזרה אחורה: revert ל־commit קודם דרך PR; workflow יפרסם מחדש את הבנייה.

ההרצה מתעדכנת אוטומטית לאחר שינוי תקין, עם debounce של 450ms. Worker קודם מבוטל לפני הרצה חדשה; תוצאות קודמות מסומנות במפורש. אפשר לעצור חישוב כבד. שיתוף מעתיק את כל הפרמטרים ואת ה־seed בכתובת; אין שיתוף של סודות או נתונים אישיים.
