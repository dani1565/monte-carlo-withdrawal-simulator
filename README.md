# מבחן המשיכה

סימולטור מונטה קרלו בעברית ו־RTL למשיכות שנתיות מתיק השקעות, להשוואת שיטות משיכה ובדיקת ההכנסה והיתרה לאורך זמן.

האתר מיועד למידע, לימוד והמחשה בלבד ואינו ייעוץ השקעות.

## מה אפשר לבדוק

- השוואת 1–6 שיעורי משיכה על אותם מסלולי שוק.
- סכום נומינלי קבוע מתוך ההון ההתחלתי, סכום צמוד למדד, ואחוז מהיתרה במועד המשיכה.
- משיכה בתחילת כל שנה או בסופה; אינפלציה שנתית קבועה הניתנת לשינוי.
- מימון מלא של תוכנית המשיכות, התרוקנות, הכנסה שנתית, יתרה, אחוזונים ומדדי זנב.
- שקלים נומינליים מול כוח הקנייה של היום; גרפים וטבלה שנתית.
- seed לשחזור, קישור לשיתוף, שמירת הגדרות מקומית וייצוא CSV הכולל הנחות ותוצאות.

כל החישוב בדפדפן וב־Web Worker. אין שרת חישוב, חשבונות, שירותי AI, מפתחות API, נתוני שוק חיים או מעקב שימוש. הגופנים נכללים בבנייה ואינם נטענים משירות צד שלישי.

## הפעלה

נדרש Node.js 22 ומעלה.

```sh
npm ci
npm run dev
```

```sh
npm run check:fast   # בדיקות יחידה ורכיב + TypeScript
npm run build        # תוצר סטטי ב־dist
npx playwright install chromium
npm run check:release # יחידה, רכיב, TypeScript, בנייה ודפדפן במחשב ובנייד
```

אפשר להגדיר `CHROMIUM_PATH` להפעלת בדיקות מול Chromium מותקן. `npm run preview` מגיש את הבנייה המקומית.

## הקשר לכלי המקורי

בסיס המחקר: commit `dbe69dc3bdc8d0dee64c01bff5c887b305682816` בריפו המינוף. נשמרו צבעים, טיפוגרפיה, RTL, כרטיסי מדדים, הסברים סמוכים לשדות ומבנה הבקרה/תוצאות. מודל השוק והמחולל האקראי נשמרו, ו־regression fixture מאמת התאמה מספרית למסלול 1× ללא משיכות.

הון ברירת המחדל הוא מיליון ₪ ותקופת המשיכות 30 שנים, כדי להציג תכנון משיכות מובן. פרמטרי השוק כברירת מחדל הם 9%, 18%, df=4.2, 252 ימים, 2,000 מסלולים ו־seed=2026. ערך df=4.2 נבחר כנקודת פתיחה בקירוב באזור 4, בהתאם לספרות על תשואות יומיות של מדדי מניות, וזהה לתרחיש ״בסיס שוק אמריקאי״. זהו פרמטר סינתטי ולא כיול למדד ותקופה מסוימים. כל ערך ניתן לעריכה. תרחישי השוק שומרים את אופק המשיכה שבחר המשתמש, ומשנים רק תשואה, תנודתיות ו־df. שמותיהם אינם טענה לשחזור היסטורי.
